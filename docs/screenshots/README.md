# MediLocker Screenshots Guide

No UI screenshot image files are currently committed in `docs/screenshots/`.

When capturing screenshots for submission or documentation, capture the following views from `http://127.0.0.1:3001` at `1440×900` using synthetic data only:

1. `01-login-offline-demo.png` — `/login` showing Offline Local Demo Mode, Email OTP, and Google Sign-In options.
2. `02-dashboard-empty.png` — `/dashboard` showing `NOT_RUN` / `NOT_MEASURED` empty states and the first-run onboarding panel.
3. `03-datasets-upload.png` — `/dashboard/datasets` showing synthetic dataset upload and live stage progression.
4. `04-dashboard-populated.png` — `/dashboard` after processing showing Release Readiness, 3×2 Metric Grid, 6-stage Processing Workflow, Recent Jobs, and Audit Events.
5. `05-identity-continuity.png` — `/dashboard/identity-continuity` showing pseudonymous `PSN-XXXXXX` clusters and hospital links.
6. `06-privacy-passport.png` — `/dashboard/privacy-passports` showing `UNSIGNED` SHA-256 hash-verified passport cards.
